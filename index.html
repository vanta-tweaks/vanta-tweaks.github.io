Is it safe?
Yes. Nothing changes until you say so, and one click puts it all back.
Can I get banned?
We never touch game files. Core Tuner changes how Windows runs your game, so it warns you first on games with strict anti-cheat, like VALORANT or FACEIT.
Will it work on my PC?
Core Tuner runs on any Windows 10 or 11 PC. BIOS Tuner needs a desktop board with an AMI BIOS (most ASUS, MSI, Gigabyte and ASRock).
